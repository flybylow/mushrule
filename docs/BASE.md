# Knowledge base conventions

Internal docs live in `docs/`. The repo root stays minimal (config, `README.md`, source only).

## Rules

- One focused note per topic; lowercase `kebab-case.md` filenames.
- Date-prefix (`YYYY-MM-DD-short-topic.md`) only when order matters.
- Update `docs/INDEX.md` whenever a knowledge file is added, renamed, or removed.
- Do not leave internal `.md` guides at the repo root. `README.md` is the only exception.

## What belongs here

Non-obvious facts this project will hit again: Strudel embed pitfalls, extraction parameters, sketch provenance, sensor mapping, export filenames.
