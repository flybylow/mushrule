# Mushrule

Singing Bowls Pattern Reader — scan an image (craquelure, cuneiform, glaze) into a Strudel pattern and play it in the browser.

```bash
npm install
npm run dev
```

Opens [http://localhost:5174/](http://localhost:5174/). Draw a region on the tablet to start.

Internal notes live in [docs/](docs/INDEX.md). HTML prototypes stay in `sketches/`.
